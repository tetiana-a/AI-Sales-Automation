# 🚀 AI Sales Automation Platform

Production-ready AI Sales Automation system built with **n8n, OpenAI, PostgreSQL, Telegram, HAPP Voice AI and CRM integrations**.

This project automates the complete sales pipeline — from the first customer interaction to AI analysis, CRM updates, reporting and manager notifications.

---

# ✨ Features

✅ AI Voice Calling

✅ Lead Qualification

✅ OpenAI-powered Conversation Analysis

✅ Automatic CRM Updates

✅ AI Lead Scoring

✅ Telegram Notifications

✅ Weekly CEO Reports

✅ Callback Scheduling

✅ Sales Analytics Dashboard
